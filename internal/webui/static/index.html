Steam account

The Starbound dedicated server can only be downloaded by an account that owns the game. Credentials are stored on the data volume (mode 0600) and never returned by the API.

If the account uses the Steam mobile authenticator, steamcmd waits for a confirmation. Approve it in the app, or paste the current 5-character code above and press Test login right away. A successful login is cached on the data volume, so this is a one-time step.

Create a free key at steamcommunity.com/dev/apikey. It is only used to search the Workshop; item details work without it.
